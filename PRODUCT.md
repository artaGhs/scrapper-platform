# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Business owners seeking public conversations where someone explicitly requests a solution they offer. Early small B2B SaaS and Shopify app founders are a research hypothesis, not validated customers.

## Product Purpose

Describe a business, Run a bounded search, review a short ranked list and open the original discussion to participate manually and transparently.

## Positioning

Explainable solution-request discovery with minimal onboarding. AI filtering is not a novel category claim. Success means useful real opportunities, not guaranteed buyers.

## Operating Context

A desktop or mobile browser, a short product description, and original public discussions. Assumed scene: a founder checking opportunities between other work; visual choices are delegated for this build.

## Capabilities and Constraints

One-page Next.js/React prototype with strict TypeScript for app, API, provider/storage and future AWS integration logic, server-only credentials, persistent session-owned scans, truthful progress, up to ten matches. Public launch uses Reddit only, with actual source progress; X is deferred and excluded from public scan creation; absent credentials default to clearly labeled synthetic examples. Vercel deployment with free Neon durable storage is authorized. Paid live calls require pilot access and explicit server budgets. X, Instagram and TikTok are deferred from this Reddit-only release; YouTube is outside scope. No checkout or automatic outreach. AWS-track payment-service eligibility remains unconfirmed; Amazon Pay and AWS Marketplace billing are distinct candidates.

## Brand Commitments

Project name Scrapper platform. Plain factual language, very simple landing directly connected to chat. No existing visual assets or established style.

## Evidence on Hand

README.md, docs/research.md, docs/mvp-plan.md, docs/validation.md. Three explicitly authorized Apify attempts reported $0.092 total charges. The corrected ten-item check succeeded with seven real posts containing text, original URLs and dates; all normalized, but none qualified for the supplied business. Useful query precision remains unproven. One bounded X free-demo validation returned ten real posts with text, original URLs and dates, reported $0.020, and yielded no qualified matches. Current free X entitlement is ten items per run and five runs per month; commercial resale rights and useful search coverage remain unverified. One separate Gemini query-drafting generation passed using 96 input and 36 output tokens; service wiring and fallback are tested with an injected model. No testimonials, customer outcomes or commercial permission. Synthetic demonstration content must be unmistakable and have no invented original links.

## Product Principles

- Explain fit from observed content and confirmed capabilities.
- Separate sample examples from live discovery.
- Keep the first useful action immediate.
- Bound data, time and cost; preserve original provenance.
- Humans decide whether and how to respond.

## Accessibility & Inclusion

Keyboard operation, readable contrast, responsive layout and reduced-motion support are required by this implementation brief.

### Final launch scope (October 11, 2026)

User narrowed launch to Reddit only. Public UI and scan creation expose Reddit only; X code is retained privately as deferred work. Category/problem searches target verified communities where known, use the past year with honest age labels, and do not require every optional feature in the source request. Gemini now performs a bounded exact-evidence context assessment of up to five candidates; deterministic queries preserve recall. The hosted useful-result release gate is recorded separately from historical transport-only tests in docs/validation.md. No payments, customer acquisition or outreach are implemented.
